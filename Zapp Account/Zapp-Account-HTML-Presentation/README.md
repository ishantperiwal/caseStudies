# Zapp Account HTML presentation

Open `index.html` to start the eleven-chapter presentation.

For continuing this project in a new conversation, attach or paste `CHAT-CONTEXT.md`.

## Presenting

- Use **Previous** and **Next**, or the arrow keys, to move through chapters.
- Use **Present** for full-screen mode.
- The Video KYC and Account Home chapters include interactive product views.
- Motion automatically simplifies when the device requests reduced motion.

## Before the interview

Confirm the impact figures, the evidence supporting the audience definition, and the exact wording of your individual contribution and collaboration story. Those facts should remain accurate even if the presentation is shortened further.

This folder is self-contained and can be copied as one unit. The original case-study folder was not modified, and no protected backup folder was opened or read.

The presentation uses Archivo for display typography and Source Sans 3 for body/UI copy when an internet connection is available, with local system fallbacks for offline presenting.

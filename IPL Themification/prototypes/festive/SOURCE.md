# Festive themification prototype (PayZapp)

A saved copy of the festive home-screen prototype made with Vibhore Singhal, so the IPL case study can
feature it without depending on the live site.

- Live original: https://vibhoresinghal.com/reel-prototypes-site/festive.html
- Source repo: https://github.com/vibhoresinghal/reel-prototypes (built output in `dist/`), commit `a8738eb`
- Files here are byte-identical to that build; nothing is edited. Update by copying the newer `dist/` files over.

Themes (`?scene=`): `christmas`, `diwali`, `rakhi` (Raksha Bandhan), `ganesh` (Ganesh Chaturthi).
Entry: `festive.html?scene=<theme>`. Mobile layout, designed at 412 × 860.
